# Bank Dashboard

A modern, responsive banking dashboard built with Next.js, React, TypeScript, and Tailwind CSS. The app presents a polished overview of account balances, active accounts, transactions, alerts, and risk insights using mock data for demo purposes.

## Features

- Overview cards for key financial metrics
- Account list with status and balance details
- Transaction insights and pending/in-review tracking
- Alerts and portfolio risk summary
- Responsive layout for desktop and mobile screens

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000 in your browser.

## Available Scripts

- `npm run dev` - start the local development server
- `npm run build` - create a production build
- `npm run start` - run the production build locally
- `npm run lint` - run ESLint checks

## Notes

This project is a demo dashboard and uses mock data only. It does not connect to a real bank account or perform actual financial transactions.
